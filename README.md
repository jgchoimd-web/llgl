# llgl — 다이얼 키보드

오른손 엄지 **하나**로 치는 안드로이드 키보드(IME)입니다. 펄스식 전화기의 다이얼을 돌리는 동작과,
원 안쪽으로 미는 동작, 바깥쪽으로 미는 동작을 합쳐서 글자 하나를 손가락을 떼지 않고 넣습니다.
손가락 구멍이 뚫린 원판 세 장이 엄지와 함께 **눈에 보이게 돌아가고**, 구멍 아래 바닥에 인쇄된 글자가 지금 고른 글자이며,
손을 떼면 원판이 돌린 만큼 **펄스를 딸깍이며 스프링으로 제자리에 돌아옵니다**(진동 + 딸깍 소리). 바깥 원판 위 끝에는 손가락 멈춤쇠가 있습니다.
배우기 쉬움보다 한 손 속도와 편안함을 우선했고, 추천 단어는 내가 친 단어만 학습합니다(내장 사전 없음).

| 항목 | 값 |
|---|---|
| 패키지명 | `com.llgl.app` |
| minSdk / targetSdk / compileSdk | 24 / 36 / 37.2 |
| 언어 · UI | Kotlin · 키보드는 Canvas `View`, 설정 화면은 Jetpack Compose (Material 3) |
| 빌드 | Android Gradle Plugin 9.4, Gradle 9.8 (wrapper) |

## 다이얼 구조

키보드 오른쪽 아래 모서리 바로 바깥이 다이얼의 축(엄지 관절 자리)입니다. 축을 중심으로
허브와 세 개의 링이 부채꼴로 펼쳐집니다.

```
          ┌───────────────────────────── 바깥 링: 초성 자음 16칸 (123 · ㅍ ㅊ ㅁ ㅈ ㅅ ㄴ ㅇ ㄱ ㄷ ㄹ ㅎ ㅂ ㅌ ㅋ · 한/영)
          │      ┌────────────────────── 모음 링: 들어간 자리 기준 상대 틱 (ㅏ ㅣ ㅡ ㅓ ㅗ ㅜ ㅔ ㅐ ㅢ ㅚ ㅟ)
          │      │     ┌──────────────── 깊은 링: 두 번째 모음 세트 (ㅑ ㅕ ㅛ ㅠ ㅘ ㅝ ㅙ ㅞ ㅒ ㅖ)
          │      │     │   ┌──────────── 허브: 탭 띄어쓰기 · ← 지우기 · ↑ 엔터
   ───────┴──────┴─────┴───┴── 축(엄지 관절) ─
```

### 한글: 글자 하나 = 한 번의 다이얼

1. **바깥 링에 올린다 → 초성.** 링을 따라 돌리면 칸이 바뀌고, 한 칸마다 "틱" 진동이 옵니다.
   그대로 떼면 자음 하나만 들어갑니다(앞 글자에 받침으로 붙을 수 있으면 받침이 됩니다).
2. **안으로 민다 → 모음.** 들어간 자리가 0 = ㅏ. 위(시계 방향)로 한 칸 ㅣ, 아래로 한 칸 ㅡ, 다시 위로 두 칸 ㅓ …
   자주 쓰는 모음일수록 가까이 있습니다. **더 깊이 밀면** 두 번째 세트(ㅑ ㅕ ㅛ ㅠ …)로 바뀌고 틱은 다시 0부터 셉니다.
3. **다시 바깥으로 민다 → 받침.** 나온 자리가 0 = ㄴ, 위로 ㅇ ㄱ ㅂ ㄷ ㅎ ㅌ ㅋ, 아래로 ㄹ ㅁ ㅅ ㅈ ㅊ ㅍ.
   받침을 빼려면 다시 안으로 들어가면 됩니다.
4. **테두리 밖까지 밀면 된소리.** 초성 ㄱ→ㄲ ㄷ→ㄸ ㅂ→ㅃ ㅅ→ㅆ ㅈ→ㅉ, 받침 ㄱ→ㄲ ㅅ→ㅆ.
5. **뗀다.** 조합된 글자가 들어갑니다. 엄지를 움직이는 동안 위쪽 바에 결과가 크게 미리 보입니다.

- 모음 링에 **바로** 올리면 초성 ㅇ이 자동으로 붙습니다(아, 이, 우 …). 자음만 친 뒤 모음 링에 올리면 그 자음에 모음이 붙습니다.
- 겹받침(ㄳ ㄵ ㄶ ㄺ ㄻ ㄼ ㄽ ㄾ ㄿ ㅀ ㅄ)은 받침을 넣은 뒤 바깥 링에서 자음을 한 번 더 탭하면 됩니다.
- 예: **강** = ㄱ에 올림 → 안으로(ㅏ) → 밖으로 한 칸 위(ㅇ) → 뗌. **있** = 모음 링에 바로 올림 → 위로 한 칸(ㅣ) → 밖으로 세 칸 아래(ㅅ) → 테두리 밖(ㅆ) → 뗌.

| 링 | ↓ 아래로(반시계) … | 0 | … ↑ 위로(시계) |
|---|---|---|---|
| 모음 링 | ㅟ ㅢ ㅔ ㅗ ㅡ | **ㅏ** | ㅣ ㅓ ㅜ ㅐ ㅚ |
| 깊은 링 | ㅒ ㅙ ㅘ ㅛ | **ㅑ** | ㅕ ㅠ ㅝ ㅞ ㅖ |
| 받침 | ㅍ ㅊ ㅈ ㅅ ㅁ ㄹ | **ㄴ** | ㅇ ㄱ ㅂ ㄷ ㅎ ㅌ ㅋ |

### 허브 (오른쪽 아래)

탭 = 띄어쓰기 · 왼쪽으로 튕기기 = 지우기(길게 튕기면 단어 지우기) · 위로 튕기기 = 엔터(길게 = 줄바꿈) ·
꾹 누르기 = 연속 지우기 · 오른쪽/아래로 튕기기 = 커서 이동.

### 영어 · 숫자/기호

세 링에 글자가 고정되어 있고, 칸을 누른 채 링 경계를 넘어서 떼면 대문자(영어) 또는 다른 기호(기호 레이어)가 됩니다.
자주 쓰는 글자(t n s r l h d c m …)가 엄지가 쉬는 바깥 링 가운데에 있습니다. 바깥 링 양 끝의 `123` / `한/영`으로 레이어를 바꿉니다.
이메일·주소 필드는 영어로, 숫자·전화번호 필드는 기호 레이어로 자동 시작합니다.

### 추천 단어

내가 띄어쓰기·엔터·문장부호로 확정한 단어를 학습해서(유니그램 + 바이그램, 최근 것에 가중치) 위쪽 바에 최대 4개 보여줍니다.
조합 중인 글자는 자모 단위로 분해해 비교하므로 "가"만 쳐도 "강아지"가 뜹니다. 탭하면 단어가 완성되고 띄어쓰기가 붙습니다.
비밀번호 필드와 학습 금지 필드에서는 꺼집니다. 설정 화면에서 학습한 단어를 모두 지울 수 있습니다.

## 설치하고 시작하기

1. APK를 설치하고 앱을 엽니다. ("출처를 알 수 없는 앱" 허용 필요)
2. **1. 키보드 켜기** → 시스템 키보드 목록에서 "다이얼 키보드"를 켭니다.
3. **2. 키보드 선택** → 키보드 고르기에서 "다이얼 키보드"를 선택합니다.
4. **3. 연습하기** 입력창에서 돌려 보세요. 높이·틱 각도·진동·왼손 모드는 설정에서 바꿀 수 있고 바로 반영됩니다.

## 빌드하기

필요한 것: JDK 17 이상, `curl`, `unzip`. Android SDK는 아래 스크립트가 설치합니다.

```bash
# 1. Android SDK 설치 (기본 위치 /opt/android-sdk, 다시 실행해도 안전)
bash scripts/setup-android-sdk.sh

# 2. 디버그 APK 빌드
./gradlew assembleDebug
# → app/build/outputs/apk/debug/app-debug.apk

# 3. 단위 테스트와 lint
./gradlew testDebugUnitTest lintDebug
```

SDK를 다른 곳에 설치하려면 `ANDROID_HOME=/원하는/경로 bash scripts/setup-android-sdk.sh`처럼 실행하세요.
스크립트는 Gradle이 SDK를 찾을 수 있도록 `local.properties`(git 추적 제외)도 만들어 줍니다.
Android Studio를 쓴다면 이 폴더를 그대로 열면 됩니다.

디버그 APK는 저장소에 들어 있는 `app/debug.keystore`로 서명됩니다. 어느 컴퓨터(또는 CI)에서 빌드하든
서명이 같아서 이미 설치된 앱 위에 덮어 설치됩니다. 스토어 배포용 키는 아닙니다.

push마다 GitHub Actions가 디버그 APK를 빌드해 **Actions → Android CI → Artifacts → `app-debug`**에 올립니다.

## 동작 원리

- `dial/DialLayout.kt` — 순수 기하: 폭·높이·밀도 → 축 위치, 네 반지름, 링마다 키보드 사각형 안에 들어가는 각도 범위. 극좌표 변환과 칸 계산.
- `dial/DialRecognizer.kt` — 터치 한 번을 끝까지 따라가는 상태 기계. 바깥 링(절대 칸) → 안쪽(상대 틱, 더 깊이 = 두 번째 세트) → 바깥(받침 틱, 테두리 밖 = 된소리).
  영어·기호 레이어에서는 모든 링이 고정 칸이고 링 경계를 넘으면 "밀기"로 읽습니다. 허브는 탭/튕기기 분류기(`keyboard/Gesture.kt`)에 넘깁니다.
- `dial/DialTables.kt` — 틱 수 ↔ 모음/받침 표, 된소리 표. `dial/DialLayers.kt` — 레이어별 링 내용.
- `hangul/HangulComposer.kt`, `hangul/Jamo.kt` — 음절 조합 자동기와 자모 분해(접두 일치용).
- `predict/PredictionModel.kt` — 학습형 추천: 유니그램·바이그램, 감쇠, 자모 접두 검색, 텍스트 저장/복원.
- `ime/KeyboardView.kt` — 바닥에 글자를 인쇄하고 그 위에 구멍 뚫린 원판을 올려, 엄지가 잡은 원판을 인식기가 알려준 각도만큼 돌려 그립니다.
  틱마다 진동·딸깍, 놓으면 원판이 펄스 수만큼 딸깍이며 되돌아오는 스프링 애니메이션(글자당 최대 0.4초, 기다리지 않아도 다음 입력 가능). 떼는 순간 결과를 IME에 넘깁니다.
- `ime/PulseClick.kt` — 딸깍 소리를 한 번 합성해 두고 펄스마다 재생하는 `AudioTrack`.
- `ime/ThumbInputMethodService.kt` — `InputMethodService`: 결과를 조합기·편집기에 반영, 입력 필드 종류에 따른 레이어·엔터 동작, 추천 갱신.
- `MainActivity.kt` — 설정 화면: 켜기/선택 상태, 연습창, 슬라이더·스위치, 다이얼 표.

모든 순수 모듈에는 JVM 단위 테스트가 있습니다(`app/src/test`). 이 저장소의 CI는 기기 없이 빌드·테스트·lint만 합니다.
